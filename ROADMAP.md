# 🗺️ Cart-Near-Me Roadmap

Our journey from a local ledger to a global, privacy-first assistance network.

---

## 🏗️ Layer 1: The Foundation (Current Focus)
**Goal**: Establish the local-first architecture and baseline observability.
- [x] **ADR-005**: SQLDelight Schema for Intents & CartItems.
- [x] **ADR-006**: Koin 4.0 Dependency Injection Strategy.
- [/] **ADR-007**: Privacy-First Observability & Analytics (Baseline).
- [/] **UI Scaffolding**: Material 3 Bottom Navigation & Core Screen Layouts.
- [ ] **Local Matching**: Basic circular geofence logic (Pre-Grid).

---

## 🌫️ Layer 2: The Fuzzy Grid
**Goal**: Transform raw GPS coordinates into the privacy-preserving grid model.
- [ ] **Grid Logic**: Implementation of the 3x3 obfuscation grid.
- [ ] **Entropy Engine**: Cryptographic-grade masking of cell IDs.
- [ ] **Liquid Glass UI**: Refraction and glassmorphism styling across all screens.
- [ ] **Technical Monitoring**: In-app "Silent Guardian" health dashboard.

---

## 🤝 Layer 3: Collaborative Intelligence
**Goal**: Anonymous syncing and multi-device interaction.
- [ ] **Ktor Sync**: Anonymous Intent synchronization across devices.
- [ ] **Shared Clusters**: Low-PII sharing of grocery lists/tasks within a group.
- [ ] **Push Persistence**: Technical alert system for high-priority matches.

---

## 🌐 Layer 4: The Silent Network (Open Source)
**Goal**: Self-hosting, extensibility, and community sovereignty.
- [ ] **Self-Hosting Guide**: Docker-compose for full-stack deployment.
- [ ] **Plugin API**: Custom category providers (e.g., specialized store trackers).
- [ ] **OSM Integration**: Direct tie-ins with OpenStreetMap for rich location metadata.
